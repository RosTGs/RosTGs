# Бумажная мастерская RosTGs

Профиль собран как альбом чертежей: бумага #F5EFE3, графит #38342F, сетка #C6CBC6, красный карандаш #A74336. Лилит представляет проекты, объясняет схемы и ведёт посетителя к галереям, документации и релизам.

Иллюстрация создана встроенным image_gen по референсу пользователя. Запрос сохранён в assets/image-prompt.txt. Текст экскурсии находится в README.md; графические схемы и оформление карточек — в scripts/build.mjs.

Команда `npm run build` получает открытые данные GitHub и создаёт SVG. GitHub Actions выполняет обновление ежедневно и по ручному запуску. Карточки используют собственные файлы репозитория; при сбое обновления опубликованный снимок продолжает отображаться. Метрики относятся к публичным репозиториям. Языки обозначают основные языки проектов по данным GitHub.

Основа: [tryshyzov/readme-cards](https://github.com/tryshyzov/readme-cards), MIT. В vendor/readme-cards сохранены модули карточек, типографики и тем, а также исходная лицензия. Бумажная рамка добавляется при сборке поверх SVG, созданного pinCard. Для локальной сборки используется Node.js 22+ и стандартные модули.

Основная обложка доступна как PNG, схемы и карточки — как SVG с альтернативным текстом в README. Маршрут содержит мягкую анимацию красного указателя и поддерживает prefers-reduced-motion.
